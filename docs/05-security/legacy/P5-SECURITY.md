## Baseline konfigurasi keamanan

Argon2id memakai library resmi/framework. Benchmark parameter pada host tujuan dan verifikasi login/re-hash; jangan membuat kriptografi sendiri. Session server disimpan di database, dengan cookie HttpOnly/Secure/SameSite=Lax untuk alur Inertia same-origin. Session diregenerasi saat login/perubahan privilege dan mendukung revoke. Recent authentication maksimal 15 menit untuk tindakan sensitif Pemilik; batas awal inactivity 30 menit dan absolute 12 jam merupakan batas keamanan AUTONOMOUS yang dapat direview terhadap operasi G3, bukan shift engine.

CSRF wajib pada setiap mutation; GET tidak melakukan mutation. Same-origin/trusted host/proxy memakai whitelist; redirect hanya menuju path lokal yang disetujui. Rate limiter memakai bucket database-backed terpisah per identity DAN per IP serta bucket global. Batas login awal: 5 attempt/menit per identity, 10/menit per IP dan 100/menit global. Batas reset awal: 3/jam per identity, 10/jam per IP dan 100/jam global. Command terautentikasi juga bounded. Ini default teknis yang dibekukan; ukur efektivitas serta false positive pada host/network aktual dan review perubahan melalui change control. Error seragam tidak membocorkan keberadaan akun. SQL memakai parameter; input model fillable eksplisit. Output di-escape, termasuk teks dokumen; raw HTML dari input dilarang. Tidak ada fetch remote URL yang tidak aman, path filesystem arbitrer atau diagnostics yang memuat secret.

Nginx production memakai HTTPS; HSTS max-age=31536000 setelah TLS terverifikasi (includeSubDomains hanya jika seluruh subdomain terverifikasi); X-Content-Type-Options nosniff; Referrer-Policy strict-origin-when-cross-origin; Permissions-Policy menonaktifkan camera/mic/geolocation yang tidak dipakai; baseline CSP `frame-ancestors 'none'; object-src 'none'; base-uri 'self'; form-action 'self'; default-src 'self';`. Directive script/style/connect/image dipin dengan least privilege terhadap hasil compile Inertia/shadcn, logo dan font; gunakan nonce/hash bila diperlukan, tanpa unsafe-inline/eval universal. Rehearsal compatibility dan negative browser tests wajib; frontend build tidak berarti CSP PASS.

History Inertia terautentikasi harus dienkripsi dengan lifecycle key yang diuji; logout/pergantian actor membersihkan atau merotasi key. Cache privat dan event Back/Forward/bfcache harus memaksa reload serta otorisasi ulang sebelum menampilkan informasi yang tidak lagi berizin. Periksa state/tab/history lama sesudah pergantian actor dan revoke. Biaya receiving Operations tidak boleh dipersist pada remembered form/history/browser storage/session flash, bahkan bila terenkripsi; enkripsi bukan izin menyimpan payload write-only.

Seluruh kontrol memerlukan acceptance test, bukan sekadar daftar konfigurasi. Security events yang gagal memakai log aman terpisah dari business audit atomik. Password/token/cookie/API key/payload biaya penuh tidak masuk log/telemetry/source/screenshot. Hasil dependency/advisory/license dicatat saat foundation dan candidate final, bukan klaim paket sudah aman pada sesi planning.
